# Automated Linux System Provisioning

## Description
This project aims to automate Linux installations over LAN using PXE booting, Kickstart files, Arch install scripts, and Ansible for post-installation configuration.

## Structure
- **ansible/**: Contains Ansible playbooks for configuring installed systems.
- **pxe_boot/**: Files related to PXE boot setup.
- **installers/**: Kickstart and Arch install scripts.
- **docs/**: Documentation and progress tracking files.
- **scripts/**: CLI tools and utility scripts.
- **tests/**: Test environment configurations.
